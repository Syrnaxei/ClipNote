# 0002 - 文本选择工具栏插件不使用沙箱，完全开放 Web API

日期：2026-10-14
状态：已接受

## 背景

文本选择工具栏插件需要执行跳转网页、写系统剪贴板等操作。现有文本处理插件走 Web Worker 沙箱（`web/src/plugins/sandbox.ts`），但 Worker 内无法操作 DOM，做异步 RPC 桥接成本高且让插件写法复杂化。

## 决策

文本选择工具栏插件不使用沙箱，插件代码在主线程执行，可自由使用全部 Web API（`window.open`、`navigator.clipboard`、DOM 等）。宿主仅额外提供通知 API 用于成功/失败反馈。插件代码仅运行在客户端浏览器，不对服务器做操作。

## 后果

- 插件能力最大化，写法与普通网页脚本一致，实现成本最低。
- 插件代码理论上可访问页面内任何状态（含登录态、本地数据）。信任模型为「安装即信任」，与浏览器扩展同级别风险由用户自行承担。
- 该决策仅适用于文本选择工具栏插件；文本处理插件是否同样脱离沙箱未在本次决策范围内。
- 若未来引入插件市场等不可信分发渠道，需要重新审视此决策。
