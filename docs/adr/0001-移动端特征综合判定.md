# ADR-0001：移动端识别采用特征综合判定而非 UA 嗅探或纯视口宽度

移动端适配需要驱动两类变化：CSS 布局（可由视口宽度驱动）和交互方式（悬停改长按，必须由 JS 判定）。纯视口宽度无法驱动交互变化，纯 UA 嗅探对未知浏览器脆弱且 iPad 默认 Safari 伪装桌面 UA 会漏判。因此决定：以 `pointer: coarse` + `maxTouchPoints` 为主、UA 为辅做综合判定，结果写入根节点 class，CSS 与交互逻辑读取同一信号；判定与视口宽度解耦，窄窗桌面不受影响。

## 后果

- 所有自适应样式和交互分支以根节点 class 为唯一信号源，禁止各自再做独立检测。
- 触屏笔记本（如带触摸屏的 Windows 电脑）会被判定为移动端模式；因本项目为个人剪切板工具，触屏交互在该类设备上同样可用，接受此代价。
