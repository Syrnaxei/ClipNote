# 004-长按弹出底部动作面板

**Blocked by**: 003

## 目标

移动端模式下长按条目从底部弹出动作面板，可执行复制/编辑/插件/删除，与桌面操作等价。

## 涉及层

- [ ] 逻辑层：长按手势 hook（或组件内逻辑）——按下约 500ms 触发；手指位移超阈值（约 10px）或触发滚动（touchmove 超阈值）则取消；使用 pointer/touch 事件，不影响桌面（桌面模式不绑定或绑定也无副作用）
- [ ] UI层：新增底部动作面板组件——从屏幕底部滑入，含复制、编辑、插件（有启用插件时显示）、删除四项，点击执行现有对应回调（复用 `ClipboardItem` 的 `onCopyItem` / `onEditItem` / `onPlugin` / `onDeleteItem`），点遮罩或取消关闭
- [ ] UI层：`mobile` 作用域下条目抑制长按文本选中（`user-select: none` / `-webkit-user-select: none`），编辑弹窗内输入框不受影响
- [ ] 测试：Vitest 对长按手势 hook 的状态机做单测（定时触发/位移取消/滚动取消）；面板交互手动验证

## 验收标准

- 长按条目弹出底部面板，四项操作行为与桌面端一致（spec U8）
- 点遮罩/取消可关闭；面板打开期间条目其他交互不误触发；无文本选择放大镜（spec U9）
- 快速滑动列表不误弹面板；桌面模式无长按行为（回归）
