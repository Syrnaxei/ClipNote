# 001-检测模块与根节点接线

**Blocked by**: 无

## 目标

移动端模式检测模块落地并接线到 App 根节点，DevTools 设备模拟可看到 `mobile` class 出现/消失。

## 涉及层

- [ ] 逻辑层：新增 `web/src/mobileDetect.ts` 纯函数——输入 `{ matchMediaCoarse, maxTouchPoints, userAgent }`，按 ADR-0001 特征综合判定输出布尔值（`pointer: coarse` + `maxTouchPoints > 0` 为主，UA 为辅；视口宽度不参与）
- [ ] UI层：`App.tsx` 初始化时调用检测并往 `document.documentElement`（或 `.app` 根节点）写入 `mobile` class；不监听动态变化（移动端模式在会话内视为稳定，仅首次判定）
- [ ] 测试：接入 Vitest（devDependency + `test` script），对检测纯函数做单测——iPhone Safari（桌面 UA + 触摸 → true）、Android Chrome（→ true）、桌面 Chrome/Firefox（→ false）、触屏笔记本（→ true，ADR-0001 接受的代价）

## 验收标准

- `npm test` 通过全部判定组合用例
- DevTools 模拟 iPhone 时根节点出现 `mobile` class；桌面浏览器缩窄窗口无 `mobile` class（spec U1–U4）
- `npm run build`（tsc -b）无类型错误
