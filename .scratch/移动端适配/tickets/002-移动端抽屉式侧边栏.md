# 002-移动端抽屉式侧边栏

**Blocked by**: 001

## 目标

移动端模式下条目列表占满全屏，侧边栏变为可滑出的遮罩抽屉。

## 涉及层

- [ ] UI层：`mobile` class 作用域下的样式——`.main-container` 单列全屏；Sidebar 以抽屉形式覆盖在列表之上（transform 滑入滑出）+ 半透明遮罩
- [ ] 逻辑层：抽屉开合复用现有 `sidebarOpen` state；选择剪切板（`onSelectClipboard`）后自动收起抽屉；点遮罩收起
- [ ] UI层：Header 的侧边栏切换按钮在移动端保持可用，触控目标 ≥ 40×40px 视觉区域
- [ ] 测试：DevTools 设备模拟手动验证

## 验收标准

- 模拟 iPhone 视口：默认全屏显示条目列表，点按钮抽屉滑出，选剪切板/点遮罩后收起（spec U5）
- Header 三入口在移动端可点、目标够大（spec U6）
- 桌面模式侧边栏行为与改动前完全一致（回归）
