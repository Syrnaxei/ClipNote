# 003-常驻复制与添加区改造

**Blocked by**: 001（与 004 同文件，须先于 004 完成）

## 目标

移动端模式下条目复制按钮常驻可见、添加区输入框占满整行，软键盘回车可添加。

## 涉及层

- [ ] UI层：`ClipboardItem`——`mobile` 作用域下复制按钮不依赖悬停、始终显示；复制成功反馈沿用现有 copied 动画（`clipboard.ts` / `itemActions` 逻辑不变）
- [ ] UI层：`ClipboardList` footer——`mobile` 作用域下隐藏"添加"按钮与展开按钮，`.add-item-input` 占满整个 footer 模块；禁用态与占位文案语义不变
- [ ] 逻辑层：Enter 添加逻辑复用现有 `onKeyDown`（软键盘回车同样触发 keydown Enter），无新增逻辑
- [ ] 测试：DevTools 触屏模拟手动验证

## 验收标准

- 移动模式下每条条目复制按钮可见、点击复制成功（spec U7）
- 添加区无"添加"/展开按钮，输入框全宽，软键盘回车成功新增条目（spec U11–U12）
- 桌面模式悬停显隐与添加按钮行为不变（回归）
