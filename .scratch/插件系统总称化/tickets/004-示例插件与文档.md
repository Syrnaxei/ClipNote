# 004 - 示例插件 + 文档 + 手工验收

**Blocked by**: 003

## 目标
用户拿到两个可直接导入的示例 .CVT 和编写文档，能照文档写出自己的工具栏插件并跑通全流程。

## 涉及层
- [x] 产物：示例插件「豆瓣搜索」（正则匹配图书 ISBN/关键词，点击 `window.open` 跳转豆瓣搜索）与「复制选中」（`navigator.clipboard.writeText` 复制选区，resolve 带自定义文案）
- [x] 文档：`docs/PLUGINS.md` — 新增「文本选择工具栏插件」章节：.CVT 元数据字段（type/regex/button_name）、process 约定（async、resolve=成功、throw=失败、无文本出口）、免沙箱说明与风险提示（ADR 0002 信任模型）
- [x] 文档：手工验收清单（对应 spec 故事 10–17）：导入→启用→选中文本→按钮出现→点击→toast 全链路步骤及每步预期现象

## 验收标准
- 两个示例 .CVT 均可通过导入流程入库并启用
- 按验收清单逐步操作，每步现象与文档描述一致
- PLUGINS.md 中的字段说明与 parseCvt 实际校验规则一致
