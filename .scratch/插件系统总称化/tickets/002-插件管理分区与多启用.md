# 002 - 插件管理页分区展示 + 多启用 UI

**Blocked by**: 001

## 目标
用户能在插件管理页看到两类插件分区列表，且可同时启用多个工具栏插件，互不影响。

## 涉及层
- [x] UI层：`web/src/components/PluginsView.tsx` — 按 `type` 分区（文本处理插件 / 文本选择工具栏插件），各自标题与列表；每条展示类型专属信息（工具栏插件显示按钮名与正则）
- [x] UI层：启用/禁用开关沿用现有交互；服务端已保证按类型启用语义，前端无需额外处理
- [x] 逻辑层：`web/src/App.tsx` — 现有 `activePlugin`（取第一个 enabled）改为派生两个状态：文本处理单启用插件（维持现有条目悬停按钮行为不变）+ 已启用工具栏插件列表（传给 SelectionToolbar，003 消费）
- [x] UI层：`web/src/types.ts` `Plugin` 类型补 `type` 字段
- [x] 测试：现有插件视图相关测试如有则保持绿色；类型派生逻辑如可测则补单测

## 验收标准
- 导入一个文本处理插件和一个工具栏插件后，管理页分为两区正确展示
- 同时启用两个工具栏插件：两者均保持启用，无互斥
- 启用文本处理插件不影响工具栏插件的启用状态，反之亦然
- 工具栏插件显示其按钮名（≤8 字）与正则
- 条目悬停的文本处理插件入口行为与变更前一致
