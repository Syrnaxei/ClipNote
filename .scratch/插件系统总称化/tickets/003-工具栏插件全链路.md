# 003 - 选区匹配 → 工具栏按钮 → 执行 → 通知 全链路

**Blocked by**: 002

## 目标
桌面端选中条目正文文本后，正则命中的已启用工具栏插件按钮出现在选区工具栏上，点击后免沙箱执行插件代码并按 resolve/reject 自动弹出成功/失败 toast。这是本变更的核心示踪弹。

## 涉及层
- [x] 逻辑层：新增选区匹配纯函数（输入：选区文本 + 已启用工具栏插件列表；输出：命中插件列表；`RegExp.test` 语义；正则在插件加载时预编译一次，非法正则的插件跳过不崩溃）
- [x] UI层：`web/src/components/SelectionToolbar.tsx` — 工具栏追加命中插件按钮（显示 button_name），与现有「复制文本」「跳转到网页」并列；无命中时工具栏不变；工具栏宽度定位按实际按钮数量自适应（替换现有 110/220 硬编码）
- [x] 逻辑层：插件执行 — 免沙箱主线程执行（复用 `process(input)` 函数名；`new Function` 构造后以选区文本调用，`await` 返回值）；插件代码可用全部 Web API（ADR 0002），宿主不提供额外动作 API
- [x] UI层：通知 — `App.tsx` 通过 prop 向 `SelectionToolbar` 传入 notice 触发回调，复用现有 `notice-toast`；resolve → 成功 toast（resolve 带字符串则用该文案，否则默认文案含插件名）；reject/throw → 失败 toast（`Error.message` 或通用文案）；点击按钮后工具栏收起
- [x] 测试：匹配纯函数单测（单命中/多命中/无命中/非法正则跳过）；执行+通知逻辑如可测则补（resolve 带文案/不带/throw 非 Error）

## 验收标准
- 选中与某插件正则匹配的文本，按钮出现；不匹配的文本不出现；无命中时工具栏与现状一致
- 多个插件同时命中时按钮并列显示，工具栏不溢出、定位不越界
- 点击按钮后工具栏收起；插件内 `window.open` 能跳转、`navigator.clipboard.writeText` 能复制
- resolve 弹成功 toast，`resolve('自定义文案')` 显示自定义文案；throw 弹失败 toast
- 插件抛错不影响工具栏后续使用（可再次选中触发）
- 现有「复制文本」「跳转到网页」按钮行为不变
